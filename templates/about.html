About VScan

A comprehensive vulnerability scanner for web applications

Our Mission

VScan is designed to help developers and security professionals identify vulnerabilities in their web applications before they can be exploited by malicious actors. Our scanner performs thorough checks for common security issues, providing detailed reports and recommendations for remediation.

Scanning Capabilities

SQL Injection

Detects various SQL injection techniques including boolean-based, time-based, and error-based.

XSS

Identifies Cross-Site Scripting vulnerabilities in input parameters.

CSRF

Checks for missing anti-CSRF tokens in forms.

File Inclusion

Tests for Local and Remote File Inclusion vulnerabilities.

XXE

Detects XML External Entity processing vulnerabilities.

SSRF

Identifies Server-Side Request Forgery vulnerabilities.
